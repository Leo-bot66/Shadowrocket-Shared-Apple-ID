## ⚠️ 共享账号的三类真实风险（先看这段）

1. **只在「App Store」里登录，绝对不要登录「iCloud / 设置」** —— 登录 iCloud 可能导致锁机或隐私泄漏。

**Q：小火箭共享 ID 和「小火箭共享账号」是同一个东西吗？**
是同一件事的两种叫法。搜「小火箭共享ID」「共享ID」「Shadowrocket 共享账号」，指的都是「一个已购买过 Shadowrocket 的 Apple ID，多人共用，用来在 App Store 免费下载该应用」。区别只在叫法：强调账号本体时说共享账号，强调账号标识时说共享 ID。共享 ID 只解决「下载」，不解决「上网」——节点订阅是另一件事。

**Q：共享账号会被封吗？被封了怎么办？**
会。共享号同时被多人使用，触发 Apple 风控（要求验证手机号、锁定账号）属于常态，不是账号质量差。处理方式：直接换下一个号，不要在同一账号上反复尝试——重复失败会加重风控。这也是共享号只适合临时使用的原因。

**Q：哪个区最适合下载小火箭？**
美区。Shadowrocket 在美区 App Store 长期在架、价格固定，所以美区号是刚需，也是本仓库数量最多的区。港区、台区、日区、韩区只在需要下载当地独占应用时才用得上。

**Q：共享账号登录后提示要「检查 Apple ID」或「此 Apple ID 尚未在 App Store 使用过」怎么办？**
前者通常是账号刚被轮换密码，回到获取页重新取一次；后者是把账号登进了「设置」而不是 App Store，退出后改从 App Store 登录。两种情况都不需要重新下载应用，已下载的应用不会因为退出账号而消失。
